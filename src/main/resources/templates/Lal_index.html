Como usar o sistema

Selecione o tipo de polinômio, Grau 1 para Linear e Grau 2 ao 5 para Não Linearis.

Informe o ano para o qual deseja fazer a previsão.

Caso você selecione o polinômio "Múltiplo", digite também o percentual para fazer a previsão.

O sistema utilizará os dados históricos que foram organizados na plataforma KNIME para gerar a previsão solicitada.
